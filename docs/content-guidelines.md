# 教材作成ガイドライン

## 基本方針
正確性、理解しやすさ、原理と条件の説明を優先します。文法・意味・語用論を必要に応じて区別し、方言・文体・文法理論による差を「誤り」と一括りにしません。断定できない点は校閲対象として記録します。一般的な規則を示す場合にも「どの意味で」「どの文脈で」「通常」などの条件を具体的に説明します。

## 標準構成
学習目標 → 前提知識 → 定義 → 基本原理 → 構造 → 例文と和訳 → 詳細解説 → 類似表現比較 → よくある誤り → 発展 → 確認問題 → 解答・解説 → まとめ → 関連単元。不要な項目は理由をもって省略できます。関連・前提の教材リンクはメタデータから自動生成します。未公開単元への本文リンクを直書きしません。

## メタデータ
`id / title / description / chapter / section / level / order / prerequisites / relatedTopics / tags / status`を必須にします。IDは `ega-CC-UU`。カリキュラムがID・タイトル・章・順序・難易度・依存関係の基準です。変更時は本文メタデータも同期します。levelは基礎/標準/発展/最難関。`reviewed` には実際の人間の校閲者・日付・method:humanを記録します。

## 例文と問題
すべて原則独自作成。例文に自然な和訳と、例示している条件を付けます。文法的誤文には誤りと明記し、正しい言い換えを示します。不自然でも文法的に成立する表現は、その文脈・語用上の問題を説明します。大学名を付けて独自問題を実際の入試問題のように見せません。

四択は正答が一意になる文脈を与え、正答の根拠と誤答各肢の問題点を記述します。現在の確認問題は手動開閉であり、自動採点ではありません。自由英作文・和訳を、意味的に完全自動判定できるものとして扱いません。

## 構造表示
`SentenceStructure.astro` にparts（text/role/note）、translation、captionを渡します。roleはS/V/O/C/M。句や節の範囲・修飾先・先行詞・省略は `ClauseStructure.astro` のclauses/relations/omittedで明示します。図の色だけに依存せず、ラベルと説明を残します。5文型がすべての文法理論の唯一の分析であるかのように書きません。

## 人間の校閲
- 定義・例文・和訳・確認問題・解答が整合しているか。
- 規則が働く条件と例外を説明しているか。
- 目的語/補語、完了/過去、仮定法の時間と現実性などを混同していないか。
- 英米差・文体・複数分析を不当に誤文扱いしていないか。
- 出典・権利・独自性・前提単元が適切か。
- PC/モバイル・見出し・図の読み上げ・問題の一意性を確認したか。

AI作成の3原稿は `in-review` のままです。人間による校閲をAI自身の再確認で代替してはいけません。現在のサンプルでは一般的な高校文法の説明に範囲を限定していますが、それでも教材公開前には専門知識のある人間の校閲が必要です。

## 公開範囲
公開ビルドはreviewedのみ。校閲プレビューは全ステータスを含むためローカル専用です。リポジトリ自体はPublicであり、原稿の非公開を保証するものではありません。
